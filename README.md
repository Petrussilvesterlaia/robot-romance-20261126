One original single-line joke pickup line, under 200 characters, written to charm a robot or an AI. The program writes the line to `/output/entry.txt`, validates it against the competition gate (UTF-8 text, 1 to 200 characters, not only white space, no control characters), and verifies it by reading the file back byte for byte.

## Run it

```sh
python3 main.py
```
